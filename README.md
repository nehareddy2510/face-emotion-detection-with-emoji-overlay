# Face Emotion Detection with Emoji Overlay

## Description
A real-time face emotion recognition system that detects human facial expressions from a live webcam feed and overlays corresponding emojis on detected faces. The project uses a convolutional neural network (CNN) for emotion classification and OpenCV for face detection and real-time video processing.

## Features
- Real-time face detection using Haar Cascade Classifier  
- Facial emotion classification into seven categories  
- Live webcam-based emotion recognition  
- Emoji overlay corresponding to detected emotions  
- Emotion label display on detected faces  

## Tech Stack
- Python  
- OpenCV  
- TensorFlow / Keras  
- NumPy  

## How It Works
1. Captures live video feed using a webcam  
2. Detects faces using Haar Cascade classifier  
3. Preprocesses facial regions and feeds them into a CNN model  
4. Predicts facial emotions in real time  
5. Overlays emotion-specific emojis on detected faces
